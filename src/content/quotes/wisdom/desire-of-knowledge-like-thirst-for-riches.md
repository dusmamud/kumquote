Sterne notices a curious pattern: the more we learn, the more we want to learn. Knowledge does not satisfy curiosity; it feeds it. Each answer opens new questions, each discovery reveals how much remains unknown. The same is true of wealth — the thirst grows with the having. This is not a complaint but a description of how the mind works. A wise person accepts this hunger and directs it well, choosing what is worth pursuing. The desire to know is endless, so the real skill is choosing where to spend a finite life.
