Few sentences capture the shock of passing time so simply. One moment we are young, with endless days ahead, and the next we are wondering where the years went. The question is not really about clocks; it is about attention. Time slips fastest when we are not looking, when days blur into routine and years pass unexamined. Asking how it got so late is the first step toward living more deliberately. The antidote is presence: noticing each day, using it well, and refusing to let another year slip by unnoticed. Late is only too late if we stop noticing.
