Warhol warns that time alone changes nothing. We tell ourselves that wounds will heal, habits will improve, and problems will solve themselves with a little more time. But time is neutral; it only passes. Change requires someone to act, to make the call, to apologize, to start. Waiting is comfortable because it feels like patience, when it is often just avoidance. The calendar will keep turning whether we move or not. If we want a different life, we must change it ourselves, today, while there is still time to enjoy the result.
