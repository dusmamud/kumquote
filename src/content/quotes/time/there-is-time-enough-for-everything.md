Doing one thing at a time sounds slow, but it is the fastest way to use a day well. When attention is split across many tasks, each one takes longer and mistakes creep in, so the hours slip away without much to show for them. A single focus lets work move steadily from start to finish, and the sense of progress keeps energy up. The day does not need to be crowded to be full. It only needs each hour to be given to one purpose, fully and without hurry, so that by evening the work is truly done.
