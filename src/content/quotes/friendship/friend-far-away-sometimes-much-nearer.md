Closeness is not measured in miles. A person can sit beside us every day and still feel distant, while a friend across an ocean can feel present in every important moment. What makes a friend near is not geography but attention — the memory of shared history, the habit of thinking of each other, and the certainty that distance changes nothing. True friendship survives separation because it was never built on convenience; it was built on understanding. When we need them, the faraway friend is already there: in a message, a memory, or simply the knowledge that they care.
