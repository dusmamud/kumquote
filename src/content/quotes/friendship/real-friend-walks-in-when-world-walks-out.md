Fair-weather friends are easy to find when life is going well. True friendship is revealed in hard times, when support costs something and staying is inconvenient. Walter Winchell captures that test perfectly: a real friend moves toward you when others move away. If you have a friend like this, treasure them and return the loyalty. If you want to be such a friend, practise showing up, especially when it is difficult. That is how trust is built and how friendship becomes one of life's greatest comforts.
